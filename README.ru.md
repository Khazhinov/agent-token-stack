# agent-token-stack

[English](README.md) | Русский

Центральное версионируемое описание стека оптимизации токенов и контекста для агентов разработки
(Claude Code, Codex CLI, OpenCode): рабочие примеры конфигурации, причины принятых решений и
журнал эволюции стека.

Репозиторий рассчитан на двух читателей:

- **агент**, который настраивает или обновляет своё окружение, начинает с [AGENTS.md](AGENTS.md);
- **человек**, которому нужно понять, что делает стек и почему, читает этот README и [docs/](docs/).

Репозиторий можно передать другому человеку: его агент настроит тот же стек на своей машине, а затем
будет периодически сверяться с репозиторием и обновлять локальную установку.

## Что экономится

| Уровень | Что сокращается | Инструмент |
|---|---|---|
| Источник данных | код, который агент читает при исследовании проекта | codebase-memory-mcp (CBM) |
| Вывод оболочки | вывод `git`, тестов, сборки, `grep`, журналов | RTK |
| Выводы инструментов в контексте | крупные выводы остаются в песочнице, в контекст попадает выжимка | context-mode (Claude, OpenCode); нативные лимиты и компактизация (Codex) |
| Трафик к провайдеру | сжатие запроса целиком перед API | Headroom (по умолчанию выключен) |
| Ответы модели | объём прозы в ответах агента | Caveman |
| Генерируемый код | объём кода за счёт отказа от избыточного проектирования | Ponytail |
| Наблюдение | замер до любого автоматического сокращения | TokenEconomizer (режим shadow) |

Подробности, совместимость и подключение по средам: [docs/STACK.ru.md](docs/STACK.ru.md).

## Публичная и частная части

Всё, что попадает в git, должно быть полезно на любой машине. Особенности конкретной машины хранятся
в `local/`, который git игнорирует: профиль окружения, локальные правила, дописываемые к глобальным
инструкциям агента, частные записи журнала. `scripts/self-check.sh` отклоняет домашние пути, точки
монтирования дисков и шаблоны из `local/private-patterns.txt`, поэтому коммит не раскроет их случайно.

## Быстрый старт

```bash
git clone https://github.com/Khazhinov/agent-token-stack.git
cd agent-token-stack
cp -r local.example local          # затем описать машину в local/
```

Затем запустить агента в этой папке и попросить: `Настрой моё окружение по AGENTS.md`.

## Проверки

```bash
./scripts/self-check.sh            # тесты обоих установщиков, проверка приватности и типографики
```
