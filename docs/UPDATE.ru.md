# Обновление

[English](UPDATE.md) | Русский

Репозиторий меняется; машина, настроенная по нему, догоняет его явным обновлением. Агент выполняет
его по просьбе или когда человек спрашивает, актуален ли стек.

## 1. Проверка

```bash
git -C <repo> fetch --tags
git -C <repo> log --oneline HEAD..origin/main
cat <repo>/VERSION; git -C <repo> show origin/main:VERSION
```

Новых коммитов нет - стек актуален. Иначе прочитать новые записи `CHANGELOG.md` и `docs/JOURNAL.md`
между двумя версиями и перечислить, какие из них касаются агентов этой машины (`local/README.md`).

## 2. Применение

1. Сообщить человеку, что изменится и у каких агентов; спросить перед всем, что меняет права,
   удаляет компонент или перезапускает сессии.
2. `git -C <repo> pull --ff-only`. Локальные изменения в `local/` сохраняются: git их не отслеживает.
3. Для каждого агента этой машины:

| Агент | Команда | Затем |
|---|---|---|
| Codex | `python3 agents/codex/skills/token-stack/scripts/manage.py install` | `manage.py doctor`, новая сессия Codex |
| Claude Code | `/stack normalize` (скилл - ссылка в репозиторий, поэтому уже актуален) | `/stack`, перезапуск, если помечен |
| OpenCode | `agents/opencode/install.sh`, затем изменённые шаги [agents/opencode/README.ru.md](../agents/opencode/README.ru.md) | `agents/opencode/verify.sh` |

4. Общие бинарники (RTK, CBM) меняются, только если изменился их pin; порядок - согласованное
   обновление в [STACK.ru.md](STACK.ru.md), раздел 4.

## 3. Запись

Добавить датированную строку в `local/JOURNAL.md`: версии до и после, что применено, результаты
проверок. Если обновление выявило проблему, которую встретит любая машина, исправить её в публичной
части (см. [AGENTS.md](../AGENTS.md), раздел 4).
